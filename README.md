# dotfiles

Dotfiles untuk sistem Fedora 44 + Wayland + niri. Diorganisasi untuk [GNU Stow](https://www.gnu.org/software/stow/) — folder `home/` mereplikasi struktur `$HOME`, jadi satu perintah `stow -t ~ home` membuat symlink semua config ke lokasi yang benar.

## Struktur

```
home/
├── .zshenv                          # bootstrap: set ZDOTDIR ke ~/.config/zsh
└── .config/
    ├── kitty/
    │   ├── kitty.conf               # include theme + local
    │   ├── kitty.local.conf         # opacity, padding, font
    │   └── themes/noctalia.conf     # generated by Noctalia
    ├── mimeapps.list                # default browser & URL handlers
    ├── niri/
    │   ├── config.kdl               # WM config (keybinds, layout, rules)
    │   └── theme.kdl                # generated by Noctalia
    ├── noctalia/
    │   ├── templates.toml           # palette → niri theme template
    │   └── templates/niri-theme.kdl
    ├── nvim/
    │   ├── init.lua                 # LazyVim-style entry point
    │   ├── lua/                     # config/ + plugins/
    │   ├── plugin/                  # after/plugin/
    │   ├── lazy-lock.json           # locked plugin versions
    │   └── stylua.toml
    ├── user-dirs.dirs               # XDG folder paths
    └── zsh/
        ├── .zshrc                   # main config
        ├── aliases.zsh              # eza, bat, rg, lf, git, stream
        ├── bindings.zsh             # vi-mode cursor, Ctrl+arrows, fzf
        ├── fzf.zsh                  # Ctrl+T / Ctrl+F file picker
        ├── prompt.zsh               # starship init
        ├── plugins.zsh              # auto-clone plugin loader
        ├── starship.toml            # prompt theme
        ├── local.zsh                # machine-specific overrides (di-gitignore)
        └── plugins/                 # auto-cloned on first shell (di-gitignore)
```

## Dependensi

### WM & Desktop

| Package | Purpose | Install (Fedora) |
|---------|---------|-------------------|
| `niri` | Wayland compositor | `sudo dnf install niri` |
| `noctalia` | Bar, launcher, notifications, wallpaper, screen lock | [GitHub](https://github.com/noctalia-dev/noctalia) |
| `kitty` | Terminal emulator | `sudo dnf install kitty` |
| `fuzzel` | App launcher (fallback) | `sudo dnf install fuzzel` |
| `grim` | Screenshot tool | `sudo dnf install grim` |
| `swaybg` | Wallpaper daemon (fallback) | `sudo dnf install swaybg` |

| Tool | Purpose | Source |
|------|---------|--------|

| `eza` | `ls` replacement (icons, git integration) | [GitHub releases](https://github.com/eza-community/eza/releases) |
| `bat` | `cat` replacement (syntax highlight) | [GitHub releases](https://github.com/sharkdp/bat/releases) |
| `fd` | `find` replacement (fzf) | [GitHub releases](https://github.com/sharkdp/fd/releases) |
| `fzf` | Fuzzy finder (Ctrl+T/F, history) | [GitHub releases](https://github.com/junegunn/fzf/releases) |
| `zoxide` | Smart `cd` | [GitHub releases](https://github.com/ajeetdsouza/zoxide/releases) |

| `ripgrep` | `grep` replacement (aliased) | [GitHub releases](https://github.com/BurntSushi/ripgrep/releases) |
| `lf` | Terminal file manager | [GitHub releases](https://github.com/gokcehan/lf/releases) |
| `nvim` | Editor | `sudo dnf install neovim` |

### Font

**JetBrainsMono Nerd Font** — wajib untuk starship prompt, eza icons, dan nvim.

```bash
mkdir -p ~/.local/share/fonts && cd ~/.local/share/fonts
curl -L -o JetBrainsMono.zip "https://github.com/ryanoasis/nerd-fonts/releases/latest/download/JetBrainsMono.zip"
unzip JetBrainsMono.zip && fc-cache -f
```

## Setup Mesin Baru

### 1. Install paket dasar

```bash
sudo dnf install niri kitty grim swaybg fuzzel stow neovim zsh
```

### 2. Install CLI tools user-local

Download binary release dari GitHub masing-masing ke `~/.local/bin/`:

```bash
mkdir -p ~/.local/bin
# eza, bat, fd, fzf, zoxide, starship, ripgrep, lf
# Contoh untuk satu tool (ulangi untuk lainnya):
curl -L -o ~/.local/bin/eza "https://github.com/eza-community/eza/releases/latest/download/eza_x86_64-unknown-linux-gnu"
chmod +x ~/.local/bin/eza
```

### 3. Install Nerd Font

```bash
mkdir -p ~/.local/share/fonts && cd ~/.local/share/fonts
curl -L -o JetBrainsMono.zip "https://github.com/ryanoasis/nerd-fonts/releases/latest/download/JetBrainsMono.zip"
unzip JetBrainsMono.zip && fc-cache -f
```

### 4. Clone dotfiles & stow

```bash
git clone <repo-url> ~/dotfiles
cd ~/dotfiles
stow -t ~ home
```

### 5. Set zsh sebagai default shell

```bash
chsh -s $(which zsh)
```

### 6. Buat direktori state

```bash
mkdir -p ~/.local/state/zsh    # history
mkdir -p ~/.cache/zsh          # completion cache
```

### 7. Start shell baru

Logout/login atau `exec zsh`. Plugin zsh akan auto-clone saat shell pertama kali dibuka:

```bash
zplugin-update    # untuk update plugin nanti
```

### 8. Jalankan niri

Tambahkan ke `~/.zlogin` atau display manager:

```bash
exec niri
```

## Cara Kerja Stow

GNU Stow membuat symlink dari setiap file di `home/` ke lokasi aslinya di `$HOME`:

```
~/.config/niri           -> ~/dotfiles/home/.config/niri
~/.config/zsh           -> ~/dotfiles/home/.config/zsh
~/.config/kitty          -> ~/dotfiles/home/.config/kitty
~/.config/nvim           -> ~/dotfiles/home/.config/nvim
~/.config/noctalia       -> ~/dotfiles/home/.config/noctalia
~/.config/mimeapps.list  -> ~/dotfiles/home/.config/mimeapps.list
~/.config/user-dirs.dirs  -> ~/dotfiles/home/.config/user-dirs.dirs
~/.zshenv                -> ~/dotfiles/home/.zshenv
```

Edit file di `~/dotfiles/home/...` = edit config aktif. Tidak perlu copy manual.

## Troubleshooting

| Masalah | Solusi |
|---------|--------|
| zsh plugins tidak muncul | Pastikan `ZDOTDIR` benar; cek `ls ~/.config/zsh/plugins/` |
| Prompt kotak/tofu | Nerd Font belum terinstall atau belum di-set di kitty |
| `stow` error "already exists" | Hapus file target dulu, atau pakai `stow --adopt` |
| niri reload error | Cek `niri validate` dulu; kemungkinan `theme.kdl` hilang |
| noctalia tidak start | Pastikan tidak ada waybar/mako/swaybg yang jalan paralel |
| `~/.zshenv` hilang | Pastikan stow package `home` complete; re-run `stow -t ~ home` |

## Catatan Penting

- **Noctalia owns bar + wallpaper + notifications + lock screen.** Jangan jalankan waybar, swaybg, atau mako bersamaan — akan conflict.
- **Plugin zsh auto-clone.** `plugins.zsh` akan `git clone` plugin ke `~/.config/zsh/plugins/` saat shell pertama kali dibuka. Tidak perlu manual.
- **`local.zsh` adalah override lokal.** Semua path spesifik mesin (PATH, NVM, cargo, sbin) taruh di sana. File ini di-gitignore supaya `git pull` bersih.
- **Theme files di-generate oleh Noctalia.** `niri/theme.kdl` dan `kitty/themes/noctalia.conf` berubah setiap wallpaper ganti. Template sumber ada di `noctalia/templates/`.
- **niri config memuat `theme.kdl` via `include`.** Pastikan `theme.kdl` ada sebelum reload config, atau niri akan error.
